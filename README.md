# Codeva — лабораторна робота № 2

Семантична розмітка чотирьох сторінок: головна, каталог, деталі курсу та запис
на курс. Джерело структури й контенту — сторінка **03 Desktop 1440** у `WEB.fig`.
Стилізація належить до ЛР3, інтерактивні фільтри та оброблення форми — до ЛР4.

## Запуск і перевірка

```sh
npm ci
npm run dev
```

Відкрийте адресу, яку надрукує Vite. Якщо PowerShell блокує `npm.ps1`,
використовуйте `npm.cmd` замість `npm`.

```sh
npm run lint
npm run preview
```

Команда `lint` збирає всі чотири сторінки та перевіряє готовий HTML і конфігурації
через ESLint. Для W3C Nu Html Checker використовуйте HTML-файли з `dist/`.

Публікуйте **вміст `dist/`**. Вихідні HTML містять EJS-включення й потребують
оброблення Vite. Відносні адреси працюють і під підкаталогом репозиторію.
Кореневий `index.html` залишено для попередньої структури; збірка його не використовує.

## Повторювані блоки та schema.org

- `src/partials/header.ejs` — спільна шапка з активним пунктом навігації.
- `src/partials/footer.ejs` — спільний підвал.
- `src/partials/course-card.ejs` — картка курсу для головної та каталогу.
- `src/data/courses.json` — шість курсів із desktop-макета.
- `src/details.html` — структуровані дані schema.org типу `Course` у JSON-LD.

EJS виконується на сервері розробки й під час збирання. У `dist/` виходить
звичайний HTML для статичного хостингу.

## Адаптивні зображення

Заглушки відтворюють колір `#D9D9D9` і пропорції Figma.
Кожне зображення має три розміри в обох форматах — JPG і WebP:

| Зображення | Малий розмір | Середній розмір | Великий розмір |
| --- | --- | --- | --- |
| Прев’ю курсу | 340 × 180 | 680 × 360 | 1360 × 720 |
| Аватар викладача | 80 × 80 | 160 × 160 | 320 × 320 |

`picture` надає WebP із резервним JPG, `srcset` перелічує три розміри,
а `sizes` описує ширину відображення. Браузер обирає файл за шириною місця для
зображення та щільністю пікселів: це не жорстка прив’язка файла до пристрою.
Прев’ю має умови для ширин до 768 px, від 768 px та від 1280 px.
Аватар зберігає ширину відображення 80 px на всіх екранах.

## Підготовка до перекладів

Словник англомовного інтерфейсу: `src/i18n/en.json`.

- `data-i18n` містить ключ перекладу текстового вузла.
- `data-i18n-placeholder` позначає переклад підказки поля.
- `data-i18n-aria-label` позначає переклад доступної назви елемента.
- Ключі `catalog.<id>.<field>` пов’язують картки зі словником за ідентифікатором курсу.

Це підготовка структури: перемикач мови та завантаження перекладів поки не потрібні.
Заголовок головної має окремі ключі для звичайного й акцентного тексту, щоб
майбутня заміна тексту не знищила вкладений `span`.

## Форма

Видимі поля відповідають desktop-макету; вибраний курс передається прихованим
полем. Перевірка імені та електронної адреси працює засобами браузера.
`/enroll` — майбутня адреса обробника для ЛР4, а не реалізований сервіс
статичного хостингу.
